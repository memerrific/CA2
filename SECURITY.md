# Website security

This repository contains only public website files. Do not commit:

- passwords or recovery codes;
- personal access tokens or API keys;
- Google, Tradify, Meta or analytics secrets;
- customer names, addresses, photographs or job records not intended for publication;
- private quotations, invoices or certificates.

Third-party services must be connected through their supported hosted forms, embeds or server-side secret storage. Credentials must never be placed in HTML or browser JavaScript.

If sensitive information is committed accidentally, remove it from the repository, revoke or rotate the affected credential immediately, and review the repository history. Deleting the visible line alone is not sufficient because earlier commits remain accessible.
