# CA2 website

Public development preview for CA2 Heating & Plumbing Ltd.

The live preview is published with GitHub Pages. Search indexing is intentionally disabled while the website is under review. The existing CA2 website remains the production website until this repository is deliberately switched to the final company domain.

## Updating the site

- Website pages are plain HTML files in the repository root.
- Shared styling is in `styles.css`.
- Shared behaviour is in `script.js`.
- Images and accreditation marks are in `assets/`.
- Never commit passwords, API keys, access tokens, customer records or private job information.

## Before the final launch

1. Replace the temporary GitHub Pages address with the final CA2 domain in canonical, social and structured-data URLs.
2. Remove `noindex,nofollow` from every public page.
3. Restore the production sitemap reference in `robots.txt`.
4. Review the privacy policy, terms, accreditations and service claims.
5. Add analytics only after the measurement ID and consent arrangement are approved.

## Generated pages

Some pages are generated by small Python scripts in `tools/` (run from the repo root):

- `tools/site_shared.py`: header phone/WhatsApp, the shared footer, lazy-loaded images and asset versions across every page. Safe to re-run.
- `tools/build_guides.py`: the long-form guides (`blog-combi-conversion.html`, `blog-unvented-conversion.html`, `blog-dynamic-trvs.html`, `blog-mvhr.html`).
- `tools/build_towns.py`: the `heating-engineer-<town>.html` area pages.
- `tools/build_projects.py`: `projects.html`, the Recent Projects feed.

Edit the content in the script, then re-run it, rather than editing the generated HTML.

## Recent projects from Instagram

`projects.html` and the homepage "Latest work" strip read `data/instagram.json` and show posts with the site's own viewer. Nothing opens Instagram.

Until Instagram is connected, the file holds the existing project photos. To connect it:

1. Make sure the CA2 Instagram account is a Professional (Business or Creator) account.
2. In Meta for Developers, create a Business app, add the Instagram product ("API setup with Instagram login") and generate an access token for the CA2 account.
3. In this repository: Settings → Secrets and variables → Actions → New repository secret, named `INSTAGRAM_TOKEN`.
4. Optional, so the token renews itself: create a fine-grained GitHub token with "Secrets: read and write" on this repository and save it as a secret named `SECRETS_PAT`. Without it, the Instagram token must be replaced every 60 days.
5. Actions tab → "Update Instagram projects" → Run workflow. After that it runs every morning.

Add `#noweb` to any Instagram caption to keep that post off the website.
